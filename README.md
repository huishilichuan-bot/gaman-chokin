# 我慢貯金 v3.1.0

我慢した出費を記録して「貯金できた額」を見える化する、大人向けのPWA（iPhoneのホーム画面に追加して使えます）。

公開URL: https://huishilichuan-bot.github.io/gaman-chokin/

## v3.0.0 の主な機能
- **2タップ記録**：6グループ（食べ物・お菓子／飲み物／タバコ※20歳以上／買い物／娯楽／その他）→ 金額（100〜3,000円・自由入力）。タバコは1本（約30円）・1箱ボタン。
- **いつもの（1タップ）**：固定した項目＋よく使う組み合わせを自動で学習。時間帯に合わせた提案。
- **欲しいものリスト**：24時間後に「まだ欲しい？」→「やめた」でそのまま貯金に。
- **森となかま**：貯金額で森が育つ。6種類のなかま（条件で出会える）。レベルが上がるとゲームで有利に。
- **なかまガチャ（v3.1）**：40種類・7レアリティ（ノーマル／レア／スーパーレア／ウルトラレア／激レア／伝説／神話）。アプリ内の🔮キラ石だけで引ける（お金では買えない）。1回30・10回300（10回目はスーパーレア以上）。確率は画面で表示。かぶりは「かけら」→★で強化。パートナーのレアリティ・★でゲームが少し有利（レベルの有利に加算、上限は同じ）。キラ石は記録+3（1日30まで）・ミッション+10・ゲーム勝利+2〜15（1日20まで）、合計1日80まで。コンプリート報酬なし。
- **ズル防止**：連続タップ・1日の上限、スクワット（動きのセンサー、iPhoneは許可制、使えないときは通常記録）、✅実際に移した額／△未確認の区別。
- **ゲーム13種（CPU対戦・4段階：弱い／中／強い／ウルトラ最強）**：チェス、リバーシ、五目並べ、ミニ将棋（5×5）、神経衰弱、クライミング、アリーナバトル、ブロック崩し、もぐらたたき、ランナー、2048、ナンプレ、お金パズル。ゲームXPは1日30まで。
- そのほか：7/30/90日グラフ、年間見込み、目標と紙吹雪、週ごとの移し替えチェック、スマホ断ちタイマー、週の成績カード画像、使っちゃった＋if-thenプラン、テーマ、バックアップ（v1のファイルも読み込み可）、データ全消去。
- プレミアムは**デザインのみ**（近日公開・購入不可）。決済コードは含みません。

## データ
- すべて端末の localStorage（`gaman-chokin:v3`）。v1（`gaman-chokin:v1`）のデータは初回起動時に自動で移行し、元データも残します。v3.0 → v3.1 は同じキーのまま項目を追加（キラ石は更新した時点から、はじめてボーナス300）。
- 外部送信・解析・広告なし。

## 開発
- 依存なしの静的ファイル（`index.html`, `styles.css`, `app.js`, `forest.js`, `games*.js`, `chess.js`, `sw.js`）。
- `main` へのpushで GitHub Actions が GitHub Pages にデプロイします。
- サービスワーカーのキャッシュ名：`gaman-chokin-v3.1.0`
