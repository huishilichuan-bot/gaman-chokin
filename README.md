# 我慢貯金（がまんちょきん）

コンビニ、コーヒー、衝動買い……。我慢した小さな出費を「貯金」として見える化する、大人向けのWebアプリ（PWA）です。

**公開URL:** https://huishilichuan-bot.github.io/gaman-chokin/

## 特長
- **1タップで記録**：我慢したら項目をタップ。コインが貯金瓶に入り、合計がカウントアップ。5秒以内なら取り消し可。
- **見える化**：合計・今日/今週/今月、毎日の棒グラフ、累計の折れ線、項目ごとのドーナツ、「このペースなら1年で約◯円」、「ラーメン◯杯分」などの換算。
- **目標**：複数の目標に割合で振り分け、進捗リング・到達日の目安・達成時のお祝い。
- **本物の貯金につなげる**：週ごとに「実際に移した額」を記録。移した分は ✅、まだの分は △。
- **時間も**：スマホ断ちタイマー（アプリから離れると失敗）。取り戻した時間と時給換算。
- **続けやすさ**：レベルと称号（実際に移した額が満額反映）、1日1回でOKの連続記録＋週1枚のおやすみチケット、毎日3つのミッション、バッジ、週の成績カード画像（保存・シェア）。
- **責めない**：「使っちゃった」の記録ときっかけの振り返り、「もし〜なら〜する」作戦をホームに表示。
- **連打防止**：項目ごとの1日上限と、同じ項目の連続タップ間隔。
- **プレミアム（近日公開）**：画面デザインのみ。決済はありません。強さはお金で買えない設計。
- **設定**：項目編集、テーマ（自動/ライト/ダーク＋アクセント）、効果音・バイブ、JSONの書き出し/読み込み、「消す」と入力して全削除、年齢設定（タバコ・お酒は20歳以上のみ表示）。

## プライバシー
すべてのデータは端末の localStorage にだけ保存されます。サーバー・ログイン・広告・解析・外部APIはありません。詳しくは [legal.html](./legal.html)。

## 免責
表示される金額は記録にもとづく目安で、投資・金融・健康に関するアドバイスではありません。

## 構成
静的ファイルのみ（`index.html` / `styles.css` / `app.js` / `sw.js` / `manifest.webmanifest` / `legal.html` / `icons/`）。GitHub Pages（Actions）で配信。
