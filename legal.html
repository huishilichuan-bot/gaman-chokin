プライバシーポリシー

1. 集める情報

本アプリ「我慢貯金」（以下「本アプリ」）は、あなたが入力した項目名・金額・記録・目標・設定を、お使いのブラウザの保存領域（localStorage）にだけ保存します。運営者がこれらの情報を受け取ったり、閲覧したりすることはありません。

2. 外部への送信

本アプリは、アクセス解析、広告、外部のAPIやサーバーを利用していません。アプリのファイルは GitHub Pages から配信されるため、配信時に GitHub のサーバーが一般的なアクセスログ（IPアドレス等）を記録する場合があります。詳しくは GitHub のプライバシーに関する声明をご確認ください。

3. 動きのセンサー（スクワットで証明）

「食べ物・お菓子」の記録でスクワットを選んだときだけ、端末の加速度センサー（DeviceMotion）を使って回数を数えます。iPhoneでは最初に許可を求められます。センサーの値はその場の判定だけに使い、保存・送信はしません。許可しなくても、ほかの機能はすべて使えます。

4. 共有・書き出し

週の成績カードの共有、バックアップファイルの書き出し、「友だちとチェス」の対戦リンクの共有は、あなたが操作したときだけ行われます。対戦リンクには盤面と、あなたが入力したニックネームだけが含まれ、リンクを受け取った人が見られます。共有先での取り扱いは、各サービスの規約に従います。

5. データの削除

アプリの「設定 → すべてのデータを消す」、またはブラウザのWebサイトデータの削除で、端末内のデータはすべて消えます。消したデータは元に戻せません。機種変更の前には、バックアップの書き出しをおすすめします。

6. 未成年の方へ

タバコ・お酒に関する項目（「タバコ」グループを含む）は、20歳以上と回答した方にだけ表示されます。

利用規約

第1条（目的）

本アプリは、日々の小さな出費や習慣を「我慢した記録」として残し、その金額や時間を見える化することで、ご自身の振り返りを助けるためのツールです。

第2条（アドバイスではないこと）

本アプリに表示される金額・見込み額・換算（例：「ラーメン◯杯分」）・到達日の目安は、入力された記録にもとづく単純な計算結果であり、将来の貯蓄額や成果を保証するものではありません。本アプリは投資・金融・税務・医療・健康に関する助言を行いません。お金や健康に関する判断は、必要に応じて専門家にご相談ください。

第3条（お金の取り扱い）

本アプリはお金の送金・保管・決済を一切行いません。「実際に移した額」は、あなたがご自身で貯金口座等に移した金額を記録する機能です。本アプリのポイント（XP）・レベル・バッジ・なかま（キャラクター）・ゲームの成績は、現金や他のポイントと交換できず、購入することもできません。

第3条の2（ゲーム）

本アプリのミニゲームは、CPU（端末内のプログラム）と対戦する無料の機能です。お金を賭ける機能、課金、ガチャ、ランキングはありません。ゲームでもらえるXPは1日30までで、レベルを上げる中心は日々の我慢の記録です。レベルが上がると、ヒントや待った・時間などがゲームで少し有利になります。

第4条（有料プラン）

「プレミアム」は今後の提供を予定している機能の紹介であり、現在は購入できません。提供を開始する場合は、料金・契約期間・自動更新の有無・解約方法などを、購入前の画面で明確に表示します。

第5条（禁止事項）

本アプリの改ざん、他者への迷惑となる利用、法令に反する利用はご遠慮ください。

第6条（免責）

本アプリは現状のまま提供されます。端末やブラウザの故障・設定変更・データ削除等により記録が失われた場合でも、運営者は責任を負いかねます。大切な記録は定期的にバックアップしてください。

第7条（変更）

本規約やポリシーは、必要に応じて変更することがあります。重要な変更はアプリ内でお知らせします。
